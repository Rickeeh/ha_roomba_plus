# Roomba+ 4.5.0b3

**The third beta of 4.5.0.** Everything in 4.5.0 is listed in
[4.5.0](v4.5.0.md); this page is what changed since
[4.5.0b2](v4.5.0b2.md).

Needs *Show beta versions* in HACS. Built on **roombapy-prime 0.8.1**,
which Home Assistant installs with it.

---

## Fixed

- **"Detected blocking call to read_text ... inside the event loop"**
  in the log at start-up, reported against Roomba+ at `const.py`. The
  Classic app's error texts, new in b2, are a 500 KB table that
  roombapy-prime reads the first time an error is looked up; that was
  the first sensor update, in Home Assistant's event loop. Roomba+ now
  reads it once at start-up, outside the loop, for Classic and Prime
  robots alike, and roombapy-prime 0.8.1 reads its tables when it is
  loaded rather than at the first lookup. Nothing else changes; the
  texts are the same.
